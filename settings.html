Double authentification (2FA)

En plus de ton mot de passe, FicheAI te demande un code à 6 chiffres généré par une application sur ton téléphone. Même si quelqu'un découvre ton mot de passe, il ne peut pas entrer dans ton compte.

Chargement…
1
Installe une application d'authentification gratuite sur ton téléphone : Google Authenticator ou Microsoft Authenticator.
2
Dans l'application, appuie sur + puis scanne ce QR code.
Impossible de scanner ? Entre cette clé à la main :
3
Entre le code à 6 chiffres affiché par l'application.
Pour désactiver la double authentification, entre le code actuel de ton application.
